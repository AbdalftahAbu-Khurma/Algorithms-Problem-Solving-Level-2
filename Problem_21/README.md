
** Question : **

Write a program that reads how many license keys the user wants to generate,
then generates random keys in the following format:

XXXX-XXXX-XXXX-XXXX

Each key consists of:
- 4 parts
- Each part contains 4 random uppercase English letters (A–Z)
- Parts are separated by a dash (-)

The program should print all generated keys with their index number.

---

## Example Output
Key [1] : SDEK-TZCN-BUPN-TZUV  
Key [2] : OAFY-DNFT-KBKL-VZYR  
Key [3] : JSRL-PLMG-YWNV-CGDR
