# Problem 22 - Count Number Repetition in an Array

## Problem Description
Write a program that reads a number of elements, stores them in an array,
then asks the user to enter a number to check.

The program should:
- Print the original array
- Count how many times the given number is repeated in the array
- Print the repetition count

---

## Example Input
Enter number of elements : 5  
Elements [1] : 1  
Elements [2] : 1  
Elements [3] : 1  
Elements [4] : 2  
Elements [5] : 3  

Enter the number you want to check : 1

---

## Example Output
Original array : 1 1 1 2 3  
Number 1 is repeated 3 time(s).
